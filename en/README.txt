Virtual Hard Disk System
Author: connectsegabot

How to use:
  1. Double-click Start.bat and pick a number (recommended)
  2. Or double-click Install-System.bat directly
  3. Read USER-GUIDE.md for the details

Notes:
  - Keep this whole folder together. Copying only the bats from the root
    makes the menu report "cannot find ...".
  - Windows images (.wim / .esd / .iso) are not included in this package.
  - The first run asks for UAC elevation. That is expected: the tool creates
    partitions and edits the boot configuration.
